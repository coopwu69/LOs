# Survey Design Rules

เมื่องานเกี่ยวข้องกับฟอร์ม แบบสอบถาม แบบประเมิน หรือการเก็บข้อมูล ให้ปฏิบัติตามกฎต่อไปนี้

## Likert Scale ค่าเริ่มต้น

1 = ไม่เห็นด้วยอย่างยิ่ง  
2 = ไม่เห็นด้วย  
3 = ไม่แน่ใจ  
4 = เห็นด้วย  
5 = เห็นด้วยอย่างยิ่ง

## กฎบังคับ

- ห้ามใช้คะแนน 1–5 โดยไม่มี label อธิบายทุกระดับ
- หลีกเลี่ยงคำถามสองประเด็นในข้อเดียว (double-barreled question)
- ห้ามใช้คำถามนำหรือถ้อยคำชี้นำคำตอบ
- หนึ่งคำถามควรวัด construct เดียว
- ตั้งค่า Required เฉพาะข้อมูลที่จำเป็นต่อวัตถุประสงค์ การคำนวณ หรือกระบวนการถัดไป
- ใช้ภาษาชัดเจน เป็นกลาง กระชับ และเหมาะกับกลุ่มผู้ตอบ
- ระบุตัวเลือก “ไม่เกี่ยวข้อง/ไม่สามารถประเมินได้” เมื่อผู้ตอบอาจไม่มีข้อมูลเพียงพอ
- ห้ามนำค่าที่ขาดหายไปหรือ “ไม่เกี่ยวข้อง” ไปคำนวณเป็นคะแนนศูนย์
- แจ้งวัตถุประสงค์ ระยะเวลา การใช้ข้อมูล และความเป็นส่วนตัวก่อนเริ่มตอบ
- ทดสอบ keyboard navigation, focus, label, error message และ contrast ตาม WCAG 2.2 AA
