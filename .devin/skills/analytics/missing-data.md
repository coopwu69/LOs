# Missing Data

- แยก `unanswered`, `skipped_by_logic`, `not_applicable`, `prefer_not_to_answer` และ technical missing
- รายงานจำนวนและร้อยละ missing รายข้อและรายกลุ่ม พร้อม denominator ที่ถูกต้อง
- ตรวจ pattern ตาม section, device, cohort, เวลา และเส้นทางแบบสอบถามโดยระวัง privacy
- อย่าตีความ structural missing จาก skip logic เป็น item nonresponse
- Complete-case analysis ใช้ได้เมื่ออธิบายผลกระทบและ assumptions
- การ impute ต้องระบุวิธี ตัวแปรที่ใช้ uncertainty และเหตุผล; ห้ามเติมค่าเงียบ ๆ
- สำหรับคะแนนรวม ให้กำหนด minimum answered items และวิธี prorating ล่วงหน้า
- เปรียบเทียบผลก่อน/หลังวิธีจัดการ missing เมื่อข้อสรุปอาจเปลี่ยน
