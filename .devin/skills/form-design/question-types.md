# Question Types

เลือกชนิดคำถามตามข้อมูลที่ต้องการ ไม่ใช่ตามความสะดวกของผู้สร้าง

| ชนิด | ใช้เมื่อ | หลีกเลี่ยงเมื่อ |
|---|---|---|
| Text | ต้องการคำตอบสั้นที่คาดรูปแบบได้ | มีตัวเลือกมาตรฐานอยู่แล้ว |
| Textarea | ต้องการเหตุผลหรือข้อเสนอแนะ | ต้องนำไปคำนวณโดยตรง |
| Radio | เลือกได้หนึ่งคำตอบจาก 2–7 ตัวเลือก | เลือกได้หลายคำตอบ |
| Checkbox | เลือกได้หลายคำตอบ | ต้องบังคับเลือกเพียงหนึ่ง |
| Select | ตัวเลือกยาวหรือมีจำนวนมาก | มีตัวเลือกน้อยและควรเห็นพร้อมกัน |
| Rating/Likert | วัดทัศนคติ ความเห็น หรือระดับ | วัดข้อเท็จจริงหรือหลาย construct |
| Matrix | หลายข้อใช้ scale เดียวกัน | มือถือ, label ยาว, หรือมีหลายมิติ |
| Number | ต้องใช้ค่าตัวเลขคำนวณ | ค่าเป็นหมวดหมู่ เช่น รหัสนักศึกษา |
| Date | ต้องการวันที่จริง | ต้องการเพียงปีหรือภาคการศึกษา |
| Ranking | ต้องการลำดับความสำคัญ | รายการเกิน 7 ตัวเลือก |

ทุกคำถามต้องมี label ที่มองเห็นได้ ห้ามใช้ placeholder แทน label และต้องมีตัวเลือก “อื่น ๆ” เมื่อชุดคำตอบอาจไม่ครอบคลุม
