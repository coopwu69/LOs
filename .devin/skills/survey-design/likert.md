# Likert Scale

## ค่าเริ่มต้น 5 ระดับ

1. ไม่เห็นด้วยอย่างยิ่ง
2. ไม่เห็นด้วย
3. ไม่แน่ใจ
4. เห็นด้วย
5. เห็นด้วยอย่างยิ่ง

## Rules

- แสดง label ทุกระดับ ห้ามแสดงเพียงตัวเลข 1–5
- ใช้ anchors ที่สมมาตร ระยะเชิงความหมายใกล้เคียงกัน และเรียงทิศทางเดียวตลอดแบบสอบถาม
- ใช้ scale เดียวกันเฉพาะข้อที่วัด response dimension เดียวกัน
- หนึ่ง statement วัด construct เดียว และไม่ใช้คำปฏิเสธซ้อน
- ไม่สลับข้อบวก/ลบโดยไม่มีเหตุผล เพราะเพิ่มความผิดพลาดในการตอบ
- เพิ่ม “ไม่เกี่ยวข้อง/ไม่สามารถประเมินได้” แยกจาก midpoint เมื่อเหมาะสม
- midpoint หมายถึงความเป็นกลาง ไม่ใช่ “ไม่ทราบ”
- ระบุล่วงหน้าว่าคะแนนรวมใช้ผลรวม ค่าเฉลี่ย หรือวิธีอื่น และข้อใดต้อง reverse-score
