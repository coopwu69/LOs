# Matrix Questions

ใช้ matrix เมื่อหลาย statement ใช้ response scale เดียวกันจริง และจำนวนข้อไม่มาก

- จำกัดประมาณ 5–7 แถวต่อ matrix; แบ่งกลุ่มเมื่อยาวกว่านั้น
- ห้ามรวม constructs ต่างกันเพียงเพื่อประหยัดพื้นที่
- แสดง row label และ column label ให้สัมพันธ์กับ control สำหรับ screen reader
- บนมือถือควรเปลี่ยนเป็น card/stack ต่อคำถาม แทนตารางเลื่อนแนวนอน
- แสดง scale anchors ชัดเจนและคงลำดับเดิม
- อนุญาต “ไม่เกี่ยวข้อง” ต่อแถวเมื่อจำเป็น
- ตรวจ straight-lining แต่ห้ามสรุปว่าเป็นคำตอบไม่มีคุณภาพจากสัญญาณเดียว
- หลีกเลี่ยงการบังคับตอบทุกแถวหากบางข้ออาจไม่เกี่ยวข้องกับผู้ตอบ
