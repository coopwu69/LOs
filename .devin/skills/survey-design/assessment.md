# Assessment Design

- เริ่มจาก learning outcomes/competencies แล้วสร้าง blueprint ที่จับคู่ outcome, ระดับพฤติกรรม และจำนวนข้อ
- กำหนดหลักฐานว่าผู้ตอบ “ทำได้” อย่างไร ก่อนเขียนข้อคำถาม
- แยก formative assessment เพื่อพัฒนา ออกจาก summative assessment เพื่อตัดสินผล
- ทุกข้อควรมีคำตอบ เกณฑ์ หรือ rubric ที่ตรวจสอบได้
- Multiple choice ต้องมีคำตอบที่ดีที่สุดหนึ่งข้อและ distractors ที่สมเหตุผล
- Rubric ต้องใช้เกณฑ์ที่สังเกตได้ แต่ละระดับแยกกันชัด และไม่ใช้คำคลุมเครือเพียงอย่างเดียว
- กำหนด weight และเกณฑ์ผ่านก่อนเห็นผลจริง ห้ามปรับเพื่อให้ได้ผลตามต้องการ
- ตรวจ alignment, difficulty, discrimination, fairness และ accessibility
- รายงานความไม่แน่นอนและข้อจำกัดของคะแนน ไม่ตีความเกินหลักฐาน
