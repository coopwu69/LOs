# Net Promoter Score (NPS)

คำถามมาตรฐาน: “จาก 0 ถึง 10 คุณมีแนวโน้มมากน้อยเพียงใดที่จะแนะนำ [สิ่งที่ประเมิน] ให้เพื่อนหรือผู้ร่วมงาน”

- 0 = ไม่มีแนวโน้มอย่างยิ่ง, 10 = มีแนวโน้มอย่างยิ่ง
- Detractors = 0–6, Passives = 7–8, Promoters = 9–10
- NPS = ร้อยละ Promoters − ร้อยละ Detractors; ช่วงคะแนน -100 ถึง 100
- ไม่รวม missing/ไม่สามารถประเมินได้ในตัวหาร
- ใช้คำถามปลายเปิด optional ต่อท้ายเพื่อถามเหตุผล
- อย่าใช้ NPS เป็นตัวแทนคุณภาพทุกมิติหรือใช้เปรียบเทียบข้ามบริบทโดยไม่มี benchmark ที่เหมาะสม
- รายงานจำนวนผู้ตอบและช่วงเวลาเก็บข้อมูลร่วมกับคะแนนเสมอ
