### ชื่อแบบฟอร์ม 3 ฉบับ (ข้อความจริงในระบบ)
1. แบบประเมินผลการปฏิบัติสหกิจศึกษาจาก**สถานประกอบการ**
2. แบบประเมินนักศึกษาสหกิจศึกษาจาก**อาจารย์นิเทศ**
3. แบบสอบถาม**นักศึกษา**หลังกลับจากการปฏิบัติงานสหกิจศึกษา

(คำที่เป็นตัวหนา ระบบทำตัวหนาและขีดเส้นใต้บนหน้าตรวจสอบ เพื่อแยกฉบับได้ง่าย)

### พฤติกรรมสำคัญที่ยืนยันจากโค้ด
- **หน้าแก้ไขมีหน้าเดียวต่อหลักสูตร** ทั้ง 3 ฉบับลิงก์ไปที่ `/programs/{key}/edit` เดียวกัน
- **LOs และเกณฑ์คะแนนใช้ร่วมกัน:** ฉบับสถานประกอบการ (ขั้น "ความรู้และทักษะ", "จริยธรรมและบุคลิก") และฉบับนักศึกษา (ขั้นประเมินตนเองตาม LO) ดึงชุดคำถามเดียวกัน ฉบับอาจารย์นิเทศก็รับชุดคำถามเดียวกัน → **แก้ครั้งเดียว มีผลทุกฉบับในหลักสูตรนั้น**
- **หน้าแก้ไขแก้ได้เฉพาะ:** ชื่อหลักสูตร, หมวด, ข้อคำถาม LO (TH/EN), รหัส LO, PLO, ตัวเลือกคะแนนและคำอธิบาย ส่วนอื่น เช่น ข้อมูลทั่วไป ค่าใช้จ่ายและที่พัก ข้อเสนอแนะ **แก้ผ่านหน้านี้ไม่ได้**
- **บันทึกการแก้ไข ≠ ยืนยันการตรวจสอบ:** ใช้กล่องคนละกล่อง บันทึกลงคนละตาราง (`template_revisions` กับ `curriculum_review_confirmations`)
- ยืนยันซ้ำได้ (ปุ่ม "ตรวจซ้ำ") ระบบแสดงรายการล่าสุด

## 1. Style guide (อิงจากเว็บจริง)

| องค์ประกอบ | ค่า |
|---|---|
| สีหลัก (navy) | `#071C31` — ใช้กับฉากเปิด/ปิด และแถบคำบรรยาย |
| สีตัวอักษรบนพื้น navy | `#FFFEFB` (warm white) |
| กรอบเน้น | เส้น 4px สี amber `#F5B301` + เงานุ่ม มุมโค้ง 12px (ตัดกับ navy และพื้นขาวของเว็บ) |
| ฟอนต์ | IBM Plex Sans Thai Looped (ฟอนต์เดียวกับเว็บ) |
| คำบรรยาย | ไม่เกิน 2 บรรทัด ≈ 38 ตัวอักษร/บรรทัด ขนาด 44px แถบ navy โปร่ง 88% วางล่าง **และย้ายขึ้นบนอัตโนมัติ** เมื่อจุดที่เน้นอยู่ครึ่งล่างของจอ |
| ตัวชี้เมาส์ | ลูกศรขาวขอบดำ เคลื่อนแบบ ease-in-out 0.6–0.8 วิ + วงกระเพื่อมเมื่อคลิก |
| การซูม | 1.0× → 1.6–2.2× แบบ ease 0.8 วิ ค้างให้อ่าน ≥ 1.5 วิ แล้วซูมออก |
| เปลี่ยนฉาก | cross-fade 10 เฟรม ไม่มีเอฟเฟกต์หวือหวา |
| ป้ายขั้นตอน | ชิปมุมซ้ายบน "ขั้นที่ 1/5 · เลือกหลักสูตร" ให้ผู้ชมรู้ว่าอยู่ตรงไหน |

## 2. Storyboard + บทบรรยาย

> อักษรย่อคอลัมน์ "ที่มา": **จริง** = ภาพหน้าจอระบบจริง / **จำลอง** = ทำบนสำเนาในเครื่อง ไม่แตะเว็บจริง / **กราฟิก** = ทำใน Remotion
> ความยาวเสียงประเมินที่ ~13 ตัวอักษรไทย/วินาที ปรับจริงหลังได้ไฟล์เสียง

### ฉาก 1 — เกริ่นนำ (0:00–0:15 · 15 วิ)

| เวลา | ภาพ / การเคลื่อนไหว | ที่มา |
|---|---|---|
| 0:00–0:05 | พื้น navy · ชื่อระบบ 2 บรรทัด fade-in · โลโก้/ชื่อ "มหาวิทยาลัยวลัยลักษณ์" ใต้ชื่อ | กราฟิก |
| 0:05–0:11 | ไทม์ไลน์แนวนอน 2 จุด: "ทดลองใช้ · ภาคเรียนที่ 2 ปีการศึกษา 2569" → "เริ่มใช้ · ปีการศึกษา 2570" | กราฟิก |
| 0:11–0:15 | การ์ด: "งานของท่าน = ตรวจเนื้อหาแบบประเมินล่วงหน้า" + บรรทัดเล็ก "ยังไม่ต้องประเมินนักศึกษาจริง" | กราฟิก |

**บรรยาย:**
> ระบบตรวจสอบแบบประเมินผลลัพธ์การเรียนรู้ รายวิชาสหกิจศึกษา จะทดลองใช้ในภาคเรียนที่ 2 ปีการศึกษา 2569 และเริ่มใช้จริงในปีการศึกษา 2570 ก่อนนำไปใช้ ขอให้ทุกหลักสูตรตรวจสอบและยืนยันเนื้อหาแบบประเมิน ขั้นตอนนี้เป็นการตรวจเนื้อหาล่วงหน้า ยังไม่ต้องประเมินนักศึกษาจริง

### ฉาก 3 — ตรวจแบบฟอร์มทั้ง 3 ฉบับ (0:35–1:10 · 35 วิ)

## 4. ข้อสงสัยที่ยังตรวจสอบไม่ได้ / ต้องตัดสินใจ

1. **เปิดเว็บจริงไม่ได้** — นโยบายเครือข่ายของ environment บล็อก `los-wu.vercel.app` ยังยืนยัน layout ด้วยภาพจริงไม่ได้
2. **ไม่มีเครื่องมือสร้างเสียงภาษาไทย** ในเซสชันนี้ (ไม่มี TTS / connector ด้านเสียง)
3. **ไม่มี Remotion Skills** ติดตั้งในเซสชันนี้ — ติดตั้งแพ็กเกจ Remotion จาก npm ได้ (npm ใช้งานได้) แต่ไม่มี skill เฉพาะตามที่พรอมต์อ้าง
4. **หลักสูตรตัวอย่าง** — ยังไม่เห็นรายชื่อหลักสูตรของสำนักวิชาการจัดการ (อยู่ในฐานข้อมูลจริง ไม่อยู่ใน repo)
5. **ข้อมูลสำหรับสำเนาในเครื่อง** — ไฟล์ `data/dataset.json` ใน repo มีแค่ 13 หลักสูตร ไม่มีของสำนักวิชาการจัดการ ต้องได้ข้อมูลหลักสูตรตัวอย่าง 1 หลักสูตรจากฐานข้อมูลจริง (อ่านอย่างเดียว) หรือจำลองจากภาพหน้าจอ
6. **ส่วนที่แก้ไขผ่านระบบไม่ได้** — ข้อมูลทั่วไป ค่าใช้จ่ายและที่พัก ข้อเสนอแนะ แก้ในหน้าแก้ไขไม่ได้ ถ้าผู้ตรวจพบปัญหาในส่วนนี้ ควรแจ้งช่องทางใด? (ตอนนี้บทไม่ได้พูดถึง)
7. **ป้าย "ส่งแล้ว / ยังไม่ส่ง"** ในหน้ารายชื่อหลักสูตร — ไม่ใช่สถานะการตรวจ อาจทำให้ผู้ชมสับสน บทนี้เลือก **ไม่พูดถึง** และไม่ซูมบริเวณนั้น
8. **วันที่ใช้ปี ค.ศ.** — สถานะ "ตรวจแล้ว" แสดงเป็น dd/mm/yyyy แบบ ค.ศ. (เช่น 27/09/2026) และคำว่า "เวลา" อยู่หลังเวลา จะคงตามหน้าจอจริงและไม่แก้เว็บ
9. **COOP69** — ปรากฏในชื่อแท็บเบราว์เซอร์ ("… | COOP69") และ metadata ไฟล์ Word จะคงไว้ตามจริง บทนำอธิบายช่วงเวลาไว้แล้ว
10. **เสียงผู้บรรยาย** — ชาย/หญิง? บทเขียนแบบไม่มีคำลงท้าย ครับ/ค่ะ เพื่อใช้ได้ทั้งสองแบบ
