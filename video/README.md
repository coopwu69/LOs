# วิดีโอสอนการใช้งาน — ระบบตรวจสอบแบบประเมินผลลัพธ์การเรียนรู้รายวิชาสหกิจศึกษา

วิดีโอ Remotion (1920×1080, 30fps, ~1 นาที 30 วินาที, คำบรรยายภาษาไทยบนจอ + เสียงพากย์ภาษาไทยแบบกระชับ)
สำหรับอาจารย์และผู้รับผิดชอบหลักสูตรที่ได้รับลิงก์มาตรวจสอบแบบประเมินก่อนใช้จริง
เนื้อหาอิงจาก `web/src/lib/help-copy.ts` (คู่มือ /help)

วิดีโอเริ่มที่ **หน้าสำนักวิชา** เพราะแต่ละสำนักได้รับลิงก์ของตัวเอง (เช่น `https://los-wu.vercel.app/schools/mgt?lang=th`) ไม่ได้เห็นหน้ารวม — ตัวอย่างในวิดีโอคือ สำนักวิชาการจัดการ → บริหารธุรกิจ (โลจิสติกส์)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `scripts/capture.mjs` | เปิดเว็บจริง `https://los-wu.vercel.app` ด้วย Playwright ถ่ายภาพหน้าจอ “สะอาด” (ไม่มีกรอบแดง) ลง `public/shots/` และบันทึกพิกัดปุ่ม/แถวลง `src/shots.json` — **อ่านอย่างเดียว** ไม่กดส่งกล่องยืนยัน (สถานะ “ตรวจแล้ว” จำลองด้วยการแก้ DOM ในเบราว์เซอร์เท่านั้น) |
| `src/Tutorial.tsx` | สคริปต์วิดีโอ: ลำดับฉาก, คำบรรยาย, การซูมกล้อง, เคอร์เซอร์, กรอบไฮไลต์ (หน่วยเป็นเฟรม, 30 = 1 วินาที) |
| `src/ScreenScene.tsx` | ฉากภาพหน้าจอ: กรอบเบราว์เซอร์ + กล้อง + เคอร์เซอร์ + ไฮไลต์ + กล่องคำบรรยาย |
| `src/Cards.tsx` | ฉากการ์ดอธิบาย (เปิด, ระบบนี้คืออะไร, ถ้าพบข้อผิดพลาด, ปิด) |
| `src/engine.ts` | คณิตกล้อง/การเคลื่อนไหว + การจัดเวลาให้ตรงกับเสียงพากย์ |
| `src/narration.json` | **บทพากย์** — ฉากภาพหน้าจอ: 1 ประโยคต่อ 1 คำบรรยาย (ลำดับเดียวกับ `captions` ใน `Tutorial.tsx`); ฉากการ์ด: เล่นต่อกันตามลำดับ |
| `scripts/tts.mjs` | สร้างไฟล์เสียง `public/voice/*.mp3` ด้วย edge-tts (เสียง `th-TH-PremwadeeNeural`, เร็วขึ้น 5%) และบันทึกความยาวลง `src/voice.json` — สร้างใหม่เฉพาะประโยคที่แก้ |

### เสียงพากย์กับจังหวะภาพ

ถ้าประโยคพากย์ยาวกว่าช่วงของคำบรรยายนั้น วิดีโอจะ “ค้างภาพ” ที่ท้ายช่วงจนพากย์จบ
(ภาพเคลื่อนไหวไม่ช้าลง) — ดังนั้นแก้บทพากย์ได้อิสระ แล้วรัน `npm run tts` และเรนเดอร์ใหม่ ความยาววิดีโอจะปรับเอง
ข้อควรระวังเวลาแก้ `Tutorial.tsx`: อย่าให้การเคลื่อนกล้อง/สลับภาพ/กรอบไฮไลต์จางหาย คร่อมเวลาเริ่มของคำบรรยายถัดไป ไม่งั้นจะค้างกลางทาง

เปลี่ยนเสียง: `TTS_VOICE=th-TH-NiwatNeural npm run tts` (เสียงผู้ชาย) — บทพากย์ไม่มีคำลงท้าย ค่ะ/ครับ จึงใช้ได้ทั้งสองเสียง
หมายเหตุ: edge-tts ส่งข้อความบทพากย์ไปสังเคราะห์เสียงที่บริการออนไลน์ของ Microsoft และบางครั้งตอบว่า `NoAudioReceived` — สคริปต์ลองซ้ำให้อัตโนมัติ

## ใช้งาน

```bash
npm install

# 1) (ถ้า UI เปลี่ยน) ถ่ายภาพหน้าจอใหม่จากเว็บจริง (อ่านอย่างเดียว)
#    ใช้เครื่อง local แทนได้: CAPTURE_BASE_URL=http://localhost:3001 npm run capture
npm run capture

# 2) (ถ้าแก้บทพากย์ใน src/narration.json) สร้างเสียงใหม่ — ต้องมี python + `pip install edge-tts`
npm run tts

# 3) แก้/ดูตัวอย่าง
npm run studio

# 4) เรนเดอร์ MP4 → out/tutorial-th.mp4
npm run render
```

หมายเหตุ Windows: ถ้าเรนเดอร์ขึ้น `Failed to launch the browser process … ENOENT`
แปลว่า path ของ headless Chrome ใน `node_modules/.remotion` ยาวเกิน 260 ตัวอักษร —
ตั้ง `REMOTION_CHROME` ให้ชี้ไปที่ Chrome Headless Shell ที่อื่น เช่นของ Playwright:

```bash
export REMOTION_CHROME="$LOCALAPPDATA/ms-playwright/chromium_headless_shell-1243/chrome-headless-shell-win64/chrome-headless-shell.exe"
```
