# 1.ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา หลักสูตรนิเทศศาสตร์

ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา (Learning Outcome: LO) หลักสูตรนิเทศศาสตร์ดิจิทัล

1) ด้านความรู้ (knowledge) 

LO1 ประยุกต์ใช้ความรู้ด้านนิเทศศาสตร์ เพื่อวางแผนและแก้ไขปัญหาในการสร้างสรรค์และผลิตสื่อ หรือการสื่อสารองค์กรดิจิทัลและอีเว้นท์ (ขึ้นอยู่กับวิชาโทที่ผู้เรียนเลือก) ในสถานประกอบการได้ 

LO2 ประยุกต์ใช้แนวคิดการรู้เท่าทันสื่อและวิเคราะห์ข้อมูลข่าวสาร เพื่อนำไปใช้ในการสร้างสรรค์ผลงานในสถานประกอบการได้ 

2) ด้านทักษะ (Skills) 

LO3 มีทักษะการใช้นวัตกรรมการสื่อสารและเทคโนโลยีสื่อดิจิทัลได้ตรงตามความต้องการขององค์กรและอุตสาหกรรมสื่อดิจิทัลได้ 

LO4 มีทักษะในการผลิตเนื้อหาหลากหลายรูปแบบบนมัลติแพลตฟอร์ม เพื่อตอบสนองต่อองค์กรและอุตสาหกรรมสื่อดิจิทัล 

LO5 มีทักษะการนำเสนอเพื่อโน้มน้าวใจในการเจรจาต่อรองสำหรับงานด้านนิเทศศาสตร์ 

3) ด้านจริยธรรม (Ethics) 

LO6 แสดงออกถึงความซื่อสัตย์ มีความกตัญญู เคารพต่อกฎระเบียบ มีความรับผิดชอบต่อตนเองและสังคม และยึดมั่นตามหลักจรรยาวิชาชีพสื่อ 

4) ด้านลักษณะบุคคล (Character) 

LO7 แสดงออกถึงการมีวินัย การมีภาวะผู้นา สามารถเป็นได้ทั้งผู้นาและผู้ตาม สามารถทางานเป็นทีมและยอมรับความแตกต่างทางความคิดเห็นของผู้อื่น มีจิตอาสา และมีสุขภาวะ

แบบประเมินผลการปฏิบัติสหกิจศึกษาตามผลลัพธ์การเรียนรู้ที่คาดหวัง รูปแบบ Rubric Scoring
