# ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา-วิศวกรรมเครื่องกลฯ

หลักสูตรวิศวกรรมศาสตรบัณฑิต สาขาวิศวกรรมเครื่องกลและหุ่นยนต์

หลักสูตรปรับปรุง พ.ศ. 2567

ผลลัพธ์การเรียนรู้ของหลักสูตร (Program Learning Outcomes: PLOs)

ด้านความรู้ (Knowledge) 

	PLO1 อธิบายความรู้ทางวิทยาศาสตร์ คณิตศาสตร์ สังคมศาสตร์ มนุษยศาสตร์ เทคโนโลยีสารสนเทศ พื้นฐานทางวิศวกรรม และความรู้เฉพาะทางวิศวกรรม

	PLO2 ประยุกต์ใช้ความรู้ด้านวิศวกรรมเครื่องกล หุ่นยนต์ และระบบควบคุมอัตโนมัติ เพื่อออกแบบและสร้างแบบจำลองเบื้องต้น

	PLO3 ประยุกต์ใช้ความรู้ในการวิเคราะห์ด้านเศรษฐศาสตร์ การลงทุน และการบริหารงานวิศวกรรม เพื่อเตรียมความพร้อมสำหรับการเป็นผู้ประกอบการ

ด้านทักษะ (Skills)	

	PLO4 มีทักษะการออกแบบด้านวิศวกรรมเครื่องกล หุ่นยนต์ และระบบควบคุมอัตโนมัติ โดยคำนึงถึงความปลอดภัย เศรษฐศาสตร์ การบริหารงานทางวิศวกรรม ผลกระทบทางสิ่งแวดล้อม และพลังงาน

	PLO5 มีทักษะเลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศที่เหมาะสม เพื่อสร้างสรรค์นวัตกรรมด้านวิศวกรรมเครื่องกล หุ่นยนต์ และระบบควบคุมอัตโนมัติ

	PLO6 มีทักษะการสื่อสารภาษาไทยและภาษาอังกฤษ เพื่อใช้ในชีวิตประจำวันและในการทำงานด้านวิศวกรรมเครื่องกล หุ่นยนต์ และระบบควบคุมอัตโนมัติ ทั้งการฟัง พูด อ่าน เขียน และเสนอผลงานได้ตามวัตถุประสงค์ ในกรณีที่นักศึกษาเลือกภาษาจีนสามารถสื่อสารภาษาจีนในชีวิตประจำวันได้

ด้านจริยธรรม (Ethics)	

	PLO7 ซื่อสัตย์สุจริต รับผิดชอบ กตัญญู ปฏิบัติตนตามกฎกติกาของสังคมและจรรยาบรรณแห่งวิชาชีพตามกรอบมาตรฐานการปฏิบัติวิชาชีพวิศวกรรมเครื่องกลและหุ่นยนต์

ด้านลักษณะบุคคล (Character) 

	PLO8 สามารถดูแลสุขภาพร่างกายและจิตใจให้พร้อมต่อสิ่งแวดล้อมและสถานการณ์ที่มีการเปลี่ยนแปลง มีภาวะผู้นำ จิตอาสา มีวินัย และทำงานร่วมกับผู้อื่นในสหสาขาวิชาได้อย่างมีประสิทธิภาพ

	PLO9 พัฒนาตนเองและแสวงหาความรู้ใหม่ เพื่อประยุกต์ใช้กับงานทางด้านวิศวกรรมเครื่องกลและหุ่นยนต์

แบบประเมินผลการปฏิบัติสหกิจศึกษาตามผลลัพธ์การเรียนรู้ที่คาดหวัง

| ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา (Learning Outcome: LO)
ด้านความรู้ (Knowledge) 
LO1: ผู้เรียนสามารถระบุและแก้ปัญหาที่ซับซ้อนในงานที่ได้รับมอบหมายในสถานประกอบการ โดยประยุกต์หลักการทางด้านการออกแบบ การสร้างแบบจำลอง การลงทุน และการบริหารงานวิศวกรรมได้อย่างเหมาะสม

ด้านทักษะ (Skills)
LO2: ผู้เรียนสามารถออกแบบด้านวิศวกรรมที่ถูกต้องในสถานประกอบการ เพื่อสร้างสรรค์ผลงานที่เป็นประโยชน์
LO3: ผู้เรียนสามารถเลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศที่เหมาะสมในสถานประกอบการ เพื่อการแก้ปัญหาได้อย่างถูกต้อง
LO4: ผู้เรียนสามารถสื่อสารกับเพื่อนร่วมงานและบุคคลในสถานประกอบการด้วยภาษาไทยและภาษาอังกฤษได้อย่างเหมาะสม เพื่อให้การทำงานสำเร็จลุล่วงตามเป้าหมาย

ด้านจริยธรรม (Ethics)	
LO5: ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบและคำนึงถึงจริยธรรมในวิชาชีพ โดยพิจารณาผลกระทบต่อเศรษฐกิจ สังคม และสิ่งแวดล้อม

ด้านลักษณะบุคคล (Character) 
LO6: ผู้เรียนสามารถทำงานร่วมกับทีม ได้อย่างมีประสิทธิภาพ พร้อมทั้งแสดงบทบาทความเป็นผู้นำและการร่วมมือที่ดีตามสถานะของตนเองในทีม
LO7: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานในสถานประกอบการด้วยตนเอง |

| ผลการเรียนรู้ที่คาดหวัง | ผลการประเมิน |

| (1) ด้านความรู้ (Knowledge) |  |

| LO1: ผู้เรียนสามารถระบุและแก้ปัญหาที่ซับซ้อนในงานที่ได้รับมอบหมายในสถานประกอบการ โดยประยุกต์หลักการทางด้านการออกแบบ การสร้างแบบจำลอง การลงทุน และการบริหารงานวิศวกรรมได้อย่างเหมาะสม |   5 (ยอดเยี่ยม): ระบุและแก้ปัญหาที่ซับซ้อนได้อย่างครบถ้วน พร้อมเสนอแนวทางแก้ไขที่สร้างสรรค์ มีประสิทธิภาพสูง และตอบโจทย์ความต้องการของสถานประกอบการได้อย่างสมบูรณ์
  4 (ดีมาก): ระบุและแก้ปัญหาได้ในระดับดี พร้อมเสนอแนวทางแก้ไขที่เหมาะสม แม้จะมีข้อบกพร่องเล็กน้อยแต่ไม่กระทบต่อคุณภาพโดยรวม
  3 (ดี): ระบุปัญหาและแก้ไขได้ในระดับพื้นฐาน แต่ข้อเสนอแนวทางแก้ไขยังขาดความสมบูรณ์ในบางส่วน
  2 (พอใช้): ระบุปัญหาได้บางส่วน แต่ไม่สามารถแก้ไขได้อย่างเหมาะสม ต้องการคำแนะนำอย่างใกล้ชิด
  1 (ต้องปรับปรุง): ไม่สามารถระบุหรือแก้ปัญหาได้ และไม่มีข้อเสนอแนะแนวทางแก้ไข |

| (2) ด้านทักษะ (Skills) |  |

| LO2: ผู้เรียนสามารถออกแบบด้านวิศวกรรมที่ถูกต้องในสถานประกอบการ เพื่อสร้างสรรค์ผลงานที่เป็นประโยชน์ |   5 (ยอดเยี่ยม): ออกแบบด้านวิศวกรรมได้อย่างถูกต้อง ครบถ้วน และแปลผลได้ชัดเจน พร้อมข้อสรุปที่นำไปใช้ได้จริง
  4 (ดีมาก): ออกแบบด้านวิศวกรรมได้ดีในระดับที่เหมาะสม พร้อมข้อสรุปที่เป็นประโยชน์ แม้จะมีข้อผิดพลาดเล็กน้อย
  3 (ดี): ออกแบบด้านวิศวกรรมได้ในระดับพื้นฐาน แต่ข้อสรุปยังขาดความชัดเจนและสมบูรณ์ในบางส่วน
  2 (พอใช้): ออกแบบด้านวิศวกรรมได้เพียงบางส่วน และข้อสรุปยังไม่ชัดเจน ต้องการคำแนะนำเพิ่มเติม
  1 (ต้องปรับปรุง): ไม่สามารถออกแบบด้านวิศวกรรมหรือแปลผลได้ |

| LO3: ผู้เรียนสามารถเลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศที่เหมาะสมในสถานประกอบการ เพื่อการแก้ปัญหาได้อย่างถูกต้อง |   5 (ยอดเยี่ยม): เลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศได้อย่างถูกต้อง และสามารถแก้ปัญหาได้อย่างถูกต้อง
  4 (ดีมาก): เลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศได้ดีในระดับที่เหมาะสม แม้จะมีข้อผิดพลาดเล็กน้อยแต่ไม่กระทบต่อการทำงาน
  3 (ดี): เลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศได้ในระดับพื้นฐาน แต่ยังมีข้อผิดพลาดหรือยังไม่เหมาะสมในบางสถานการณ์
  2 (พอใช้): เลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศได้บ้าง แต่ยังไม่เหมาะสมกับสถานการณ์หรือมีข้อผิดพลาดที่ส่งผลต่อการทำงาน
  1 (ต้องปรับปรุง): ไม่สามารถเลือกใช้เครื่องมือทางวิศวกรรมและเทคโนโลยีสารสนเทศเพื่อการแก้ปัญหาได้เลย |

| LO4: ผู้เรียนสามารถสื่อสารกับเพื่อนร่วมงานและบุคคลในสถานประกอบการด้วยภาษาไทยและภาษาอังกฤษได้ |   5 (ยอดเยี่ยม): สื่อสารได้ชัดเจน เข้าใจง่าย ใช้ภาษาไทยและภาษาอังกฤษได้อย่างเหมาะสมกับสถานการณ์
  4 (ดีมาก): สื่อสารได้ดีในระดับที่เหมาะสม แม้จะมีข้อผิดพลาดเล็กน้อยที่ไม่กระทบต่อการทำงาน
  3 (ดี): สื่อสารได้ในระดับพื้นฐาน แต่ยังมีข้อผิดพลาดหรือจุดที่ไม่ชัดเจนในบางสถานการณ์
  2 (พอใช้): สื่อสารได้บ้าง แต่ยังไม่เหมาะสมกับสถานการณ์หรือมีข้อผิดพลาดที่ส่งผลต่อการทำงาน
  1 (ต้องปรับปรุง): ไม่สามารถสื่อสารได้อย่างเหมาะสมในสถานการณ์จริง |

| (3) ด้านจริยธรรม (Ethics) |  |

| LO5: ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบและคำนึงถึงจริยธรรมในวิชาชีพ |   5 (ยอดเยี่ยม): ปฏิบัติตามกฎระเบียบทุกข้ออย่างเคร่งครัด พร้อมแสดงความซื่อสัตย์และความรับผิดชอบอย่างชัดเจน
  4 (ดีมาก): ปฏิบัติตามกฎระเบียบส่วนใหญ่ และแสดงความรับผิดชอบในงานได้ดี แม้จะมีข้อผิดพลาดเล็กน้อย
  3 (ดี): ปฏิบัติตามกฎระเบียบได้ในระดับพื้นฐาน แต่ยังต้องการการปรับปรุงในบางส่วน
  2 (พอใช้): ปฏิบัติตามกฎระเบียบได้เพียงบางข้อ และยังมีการละเลยหรือผิดพลาดบ้าง
  1 (ต้องปรับปรุง): ไม่ปฏิบัติตามกฎระเบียบ และแสดงถึงความขาดความรับผิดชอบในงาน |

| (4) ด้านลักษณะบุคคล (Character) |  |

| LO6: ผู้เรียนสามารถทำงานร่วมกับทีม ได้อย่างมีประสิทธิภาพ พร้อมทั้งแสดงบทบาทความเป็นผู้นำและการร่วมมือที่ดี |   5 (ยอดเยี่ยม): มีบทบาทสำคัญในทีม ช่วยสร้างสภาพแวดล้อมการทำงานที่ดี และแสดงภาวะผู้นำได้อย่างชัดเจน
  4 (ดีมาก): ทำงานร่วมกับทีมได้ดีในระดับที่เหมาะสม และปฏิบัติงานตามบทบาทที่ได้รับอย่างสมบูรณ์
  3 (ดี): ทำงานร่วมกับทีมได้ในระดับพื้นฐาน แต่ยังต้องปรับปรุงในบางด้าน
  2 (พอใช้): ทำงานร่วมกับทีมได้บางส่วน แต่มีปัญหาในการสื่อสารหรือการมีส่วนร่วม
  1 (ต้องปรับปรุง): ไม่สามารถทำงานร่วมกับทีมได้อย่างเหมาะสม |

| LO7: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานในสถานประกอบการด้วยตนเอง |   5 (ยอดเยี่ยม): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้อย่างรวดเร็วและนำไปประยุกต์ใช้ในงานได้อย่างมีประสิทธิภาพ มีการริเริ่มในการศึกษาข้อมูลเพิ่มเติมด้วยตัวเอง และแสดงผลลัพธ์ที่ชัดเจน
  4 (ดีมาก): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้ดี และสามารถนำไปใช้ในงานได้ในระดับที่เหมาะสม แม้จะมีการปรับปรุงในบางส่วน
