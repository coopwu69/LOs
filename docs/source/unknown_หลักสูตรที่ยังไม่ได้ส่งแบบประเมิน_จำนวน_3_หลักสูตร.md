# หลักสูตรที่ยังไม่ได้ส่งแบบประเมิน จำนวน   3  หลักสูตร

> Source: `หลักสูตรที่ยังไม่ได้ส่งแบบประเมิน จำนวน   3  หลักสูตร.docx`

หลักสูตรที่ยังไม่ได้ส่งแบบประเมิน จำนวน   3  หลักสูตร ประกอบด้วย

หลักสูตรอาชีวอนามัยและความปลอดภัย

หลักสูตรบริหารธุรกิจบัณฑิต สาขาการจัดการธุรกิจและการเงินยุคดิจิทัล

หลักสูตรรัฐศาสตร์ (อาเซียนศึกษา) ** อาจารย์นิศาชล แจ้งว่าตอนนี้มีเด็กรหัส 66 กำลังเรียนปี 3 ใช้แบบประเมินร่วมกับความสัมพันธ์ระหว่างประเทศ
