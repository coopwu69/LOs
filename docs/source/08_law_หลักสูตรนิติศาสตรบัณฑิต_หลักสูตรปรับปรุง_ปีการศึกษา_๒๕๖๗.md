ผลลัพธ์การเรียนรู้ของหลักสูตร (Program Learning Outcomes: PLOs)

	หลักสูตรมุ่งผลิตบัณฑิตที่ตอบสนองทิศทาง นโยบาย ยุทธศาสตร์ชาติและมหาวิทยาลัย ตลอดจนความต้องการของผู้มีส่วนได้ส่วนเสีย และสอดคล้องตามเกณฑ์ 4 ด้าน ตามประกาศคณะกรรมการมาตรฐานการอุดมศึกษา เรื่อง รายละเอียดผลลัพธ์การเรียนรู้ตามมาตรฐานคุณวุฒิระดับอุดมศึกษา พ.ศ. 2565 รวมทั้งการมุ่งเน้นในการผลิตบัณฑิตที่มีความสามารถในการคิดวิเคราะห์และสังเคราะห์ สามารถแสวงหาความรู้ได้ตลอดชีวิต บนพื้นฐานของการมีจิตสำนึก มีความกตัญญู มีวินัย และรับผิดชอบต่อสังคม โดยบัณฑิตที่สำเร็จการศึกษาในหลักสูตรนี้มีความสามารถแต่ละด้านดังนี้

1) ด้านความรู้  (Khowledge)

	PLO1 อธิบายความรู้ทางด้านมนุษยศาสตร์ สังคมศาสตร์ทั่วไป พื้นฐานเทคโนโลยีสารสนเทศ วิทยาศาสตร์พื้นฐาน ทฤษฎีกฎหมายพื้นฐาน กฎหมายเฉพาะ แนวคำพิพากษา คำวินิจฉัย และความเห็นทางด้านกฎหมายขององค์กรวิชาชีพในกระบวนการยุติธรรม

	PLO2 คิดวิเคราะห์ โดยอาศัยข้อเท็จจริงจากโจทย์คำถามหรือกรณีตัวอย่างคดีในสังคมปัจจุบันและข้อมูลรอบด้านมาประกอบการพิจารณาวินิจฉัยเพื่อให้ได้มาซึ่งคำตอบที่ชัดแจ้ง

	PLO3 วิพากษ์ วิจารณ์ สนับสนุน โต้แย้ง โดยใช้แนวคิด ทฤษฎี หลักกฎหมาย เพื่อนำไปสู่ข้อยุติ การเสนอทางออกหรือกระบวนการยุติธรรมทางเลือกอื่นได้

	PLO4 ประยุกต์ความรู้ทางด้านกฎหมายเพื่อนำไปใช้ในการจัดทำเอกสารทางกฎหมาย และการปฏิบัติงานตามวิชาชีพทางกฎหมายได้

2) ด้านทักษะ (Skills)

PLO5 มีทักษะการวิจัยทางกฎหมายโดยเชื่อมโยงแบบบูรณาการกับศาสตร์อื่น ๆ ที่เกี่ยวข้องได้

PLO6 มีทักษะการสื่อสารภาษาไทยและภาษาอังกฤษเพื่อใช้ในชีวิตประจำวันและในการทำงานด้านกฎหมาย ทั้งการฟัง พูด อ่าน เขียน และเสนอผลงานได้ตามวัตถุประสงค์ ในกรณีที่นักศึกษาเลือกภาษาจีนสามารถสื่อสารภาษาจีนในชีวิตประจำวันได้

	PLO7 มีทักษะในการประยุกต์ใช้เทคโนโลยีสารสนเทศในการค้นคว้าเพื่อประโยชน์แก่การพัฒนา

องค์ความรู้อย่างรอบด้าน โดยครอบคลุมทั้งกฎหมายไทย กฎหมายต่างประเทศ รวมถึงสนธิสัญญาระหว่างประเทศ

	PLO8 มีทักษะการดูเลตนเอง เพื่อสร้างสุขภาวะ

	PLO9 มีทักษะการปฏิบัติงานที่เกี่ยวข้องกับวิชาชีพทางกฎหมาย การให้คำปรึกษาด้วยการใช้และการตีความกฎหมายโดยคำนึงถึงหลักความยุติธรรม และหลักนิติธรรม

	PLO10 มีทักษะการคิดวิเคราะห์เพื่อวินิจฉัยปัญหาโดยใช้ทฤษฎี หลักการ แนวคิด บทบัญญัติของกฎหมายเฉพาะด้านหรือกฎหมายพิเศษไปปรับใช้กับข้อเท็จจริงต่าง ๆ ที่เกิดขึ้น

3) ด้านจริยธรรม (Ethic)

	PLO11 แสดงออกถึงความซื่อสัตย์ ความกตัญญู ความรับผิดชอบ เคารพกฎระเบียบ และประพฤติตนตามจรรยาบรรณวิชาชีพ

4) ด้านลักษณะบุคคล (Character)

	PLO12 แสดงออกถึงความเป็นผู้นำ มีจิตอาสา มีวินัย สามารถทำงานร่วมกับผู้อื่น ยอมรับฟังความคิดเห็นและความเห็นที่แตกต่าง ประพฤติปฏิบัติตนอย่างมีนิติทรรศนะ 

	PLO13 แสดงออกถึงความใฝ่รู้ใฝ่เรียน และพัฒนาตนเองอย่างต่อเนื่อง

แบบประเมินผลการปฏิบัติสหกิจศึกษาตามผลลัพธ์การเรียนรู้ที่คาดหวัง

| ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา (Learning Outcome: LO)
ด้านความรู้ (Knowledge) 
LO1: ผู้เรียนสามารถระบุและแก้ปัญหาที่ซับซ้อนในงานที่ได้รับมอบหมายในสถานประกอบการ โดยประยุกต์หลักการทางวิชาชีพทางกฎหมายได้อย่างเหมาะสม

ด้านทักษะ (Skills)
LO2: ผู้เรียนสามารถรวบรวม วิเคราะห์ และแปลผลข้อมูลจากการปฏิบัติงานในสถานประกอบการ เพื่อหาข้อสรุปที่เป็นประโยชน์

LO3 ผู้เรียนสามารถสื่อสารกับเพื่อนร่วมงานและบุคคลในสถานประกอบการด้วยภาษาอังกฤษได้อย่างเหมาะสม เพื่อให้การทำงานสำเร็จลุล่วงตามเป้าหมาย
LO4: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานในสถานประกอบการด้วยตนเอง

ด้านจริยธรรม (Ethics)	
LO5:  ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบและคำนึงถึงจริยธรรมในวิชาชีพ โดยพิจารณาผลกระทบต่อเศรษฐกิจ สังคม และสิ่งแวดล้อม

ด้านลักษณะบุคคล (Character) 
LO6: ผู้เรียนสามารถทำงานร่วมกับทีม ได้อย่างมีประสิทธิภาพ พร้อมทั้งแสดงบทบาทความเป็นผู้นำและการร่วมมือที่ดีตามสถานะของตนเองในทีม |

| ผลการเรียนรู้ที่คาดหวัง | ผลการประเมิน |

| (1) ด้านความรู้ (Knowledge) |  |

| LO1:ผู้เรียนสามารถระบุและแก้ปัญหาที่ซับซ้อนในงานที่ได้รับมอบหมายในสถานประกอบการ โดยประยุกต์หลักการทางวิชาชีพทางกฎหมายได้อย่างเหมาะสม |   5 (ยอดเยี่ยม): ระบุและแก้ปัญหาที่ซับซ้อนได้อย่างครบถ้วน พร้อมเสนอแนวทางแก้ไขที่สร้างสรรค์ มีประสิทธิภาพสูง และตอบโจทย์ความต้องการของสถานประกอบการได้อย่างสมบูรณ์
  4 (ดีมาก): ระบุและแก้ปัญหาได้ในระดับดี พร้อมเสนอแนวทางแก้ไขที่เหมาะสม แม้จะมีข้อบกพร่องเล็กน้อยแต่ไม่กระทบต่อคุณภาพโดยรวม
  3 (ดี): ระบุปัญหาและแก้ไขได้ในระดับพื้นฐาน แต่ข้อเสนอแนวทางแก้ไขยังขาดความสมบูรณ์ในบางส่วน
  2 (พอใช้): ระบุปัญหาได้บางส่วน แต่ไม่สามารถแก้ไขได้อย่างเหมาะสม ต้องการคำแนะนำอย่างใกล้ชิด
  1 (ต้องปรับปรุง): ไม่สามารถระบุหรือแก้ปัญหาได้ และไม่มีข้อเสนอแนะแนวทางแก้ไข |

| (2) ด้านทักษะ (Skills) |  |

| LO2: ผู้เรียนสามารถรวบรวม วิเคราะห์ และแปลผลข้อมูลจากการปฏิบัติงานในสถานประกอบการได้ |   5 (ยอดเยี่ยม): วิเคราะห์ข้อมูลได้อย่างถูกต้อง ครบถ้วน และแปลผลได้ชัดเจน พร้อมข้อสรุปที่นำไปใช้ได้จริง
  4 (ดีมาก): วิเคราะห์ข้อมูลได้ดีในระดับที่เหมาะสม พร้อมข้อสรุปที่เป็นประโยชน์ แม้จะมีข้อผิดพลาดเล็กน้อย
  3 (ดี): วิเคราะห์ข้อมูลได้ในระดับพื้นฐาน แต่ข้อสรุปยังขาดความชัดเจนและความสมบูรณ์ในบางส่วน
  2 (พอใช้): วิเคราะห์ข้อมูลได้เพียงบางส่วน และข้อสรุปยังไม่ชัดเจน ต้องการคำแนะนำเพิ่มเติม
  1 (ต้องปรับปรุง): ไม่สามารถวิเคราะห์ข้อมูลหรือแปลผลได้ |

| LO3: ผู้เรียนสามารถสื่อสารกับเพื่อนร่วมงานและบุคคลในสถานประกอบการด้วยภาษาอังกฤษได้ |   5 (ยอดเยี่ยม): สื่อสารได้ชัดเจน เข้าใจง่าย ใช้ภาษาอังกฤษได้อย่างเหมาะสมกับสถานการณ์
  4 (ดีมาก): สื่อสารได้ดีในระดับที่เหมาะสม แม้จะมีข้อผิดพลาดเล็กน้อยที่ไม่กระทบต่อการทำงาน
  3 (ดี): สื่อสารได้ในระดับพื้นฐาน แต่ยังมีข้อผิดพลาดหรือจุดที่ไม่ชัดเจนในบางสถานการณ์
  2 (พอใช้): สื่อสารได้บ้าง แต่ยังไม่เหมาะสมกับสถานการณ์หรือมีข้อผิดพลาดที่ส่งผลต่อการทำงาน
  1 (ต้องปรับปรุง): ไม่สามารถสื่อสารได้อย่างเหมาะสมในสถานการณ์จริง |

| LO4: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานในสถานประกอบการด้วยตนเอง |   5 (ยอดเยี่ยม): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้อย่างรวดเร็วและนำไปประยุกต์ใช้ในงานได้อย่างมีประสิทธิภาพ มีการริเริ่มในการศึกษาข้อมูลเพิ่มเติมด้วยตัวเอง และแสดงผลลัพธ์ที่ชัดเจน
  4 (ดีมาก): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้ดี และสามารถนำไปใช้ในงานได้ในระดับที่เหมาะสม แม้จะมีการปรับปรุงในบางส่วน
  3 (ดี): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้ในระดับพื้นฐาน และเริ่มต้นนำไปใช้ในงานบางส่วน แต่ยังขาดความสมบูรณ์
  2 (พอใช้): นักศึกษาสามารถเรียนรู้ทักษะใหม่ได้ในระดับที่จำกัด และยังไม่สามารถประยุกต์ใช้ได้อย่างเหมาะสม
  1 (ต้องปรับปรุง): นักศึกษาไม่สามารถเรียนรู้ทักษะใหม่ได้ด้วยตนเอง และขาดความพยายามในการพัฒนาตนเอง |

| (3) ด้านจริยธรรม (Ethics) |  |

| LO5: ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบและคำนึงถึงจริยธรรมในวิชาชีพ |   5 (ยอดเยี่ยม): ปฏิบัติตามกฎระเบียบทุกข้ออย่างเคร่งครัด พร้อมแสดงความซื่อสัตย์และความรับผิดชอบอย่างชัดเจน
  4 (ดีมาก): ปฏิบัติตามกฎระเบียบส่วนใหญ่ และแสดงความรับผิดชอบในงานได้ดี แม้จะมีข้อผิดพลาดเล็กน้อย
  3 (ดี): ปฏิบัติตามกฎระเบียบได้ในระดับพื้นฐาน แต่ยังต้องการการปรับปรุงในบางส่วน
  2 (พอใช้): ปฏิบัติตามกฎระเบียบได้เพียงบางข้อ และยังมีการละเลยหรือผิดพลาดบ้าง
  1 (ต้องปรับปรุง): ไม่ปฏิบัติตามกฎระเบียบ และแสดงถึงความขาดความรับผิดชอบในงาน |

| (4) ด้านลักษณะบุคคล (Character) |  |

| LO6: ผู้เรียนสามารถทำงานร่วมกับทีม ได้อย่างมีประสิทธิภาพ พร้อมทั้งแสดงบทบาทความเป็นผู้นำและการร่วมมือที่ดี |   5 (ยอดเยี่ยม): มีบทบาทสำคัญในทีม ช่วยสร้างสภาพแวดล้อมการทำงานที่ดี และแสดงภาวะผู้นำได้อย่างชัดเจน
  4 (ดีมาก): ทำงานร่วมกับทีมได้ดีในระดับที่เหมาะสม และปฏิบัติงานตามบทบาทที่ได้รับอย่างสมบูรณ์
