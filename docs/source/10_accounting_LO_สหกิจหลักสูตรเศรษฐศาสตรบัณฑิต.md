# LO สหกิจหลักสูตรเศรษฐศาสตรบัณฑิต

> Source: `10.สำนักวิชาบัญชี 2 หลักสูตร/LO สหกิจหลักสูตรเศรษฐศาสตรบัณฑิต.docx`

หลักสูตรเศรษฐศาสตรบัณฑิต

ปรับปรุง พ.ศ. 2567

ผลลัพธ์การเรียนรู้ของหลักสูตร (Program Learning Outcomes: PLOs

1. ด้านความรู้ (Knowledge)  

PLO1	ประยุกต์ใช้ความรู้ทางวิทยาศาสตร์ เทคโนโลยี และสังคมศาสตร์ในสถานการณ์ต่างๆ เพื่อการตัดสินใจและแก้ปัญหาทางเศรษฐกิจ 

PLO2	ประยุกต์ใช้องค์ความรู้ทางเศรษฐศาสตร์เพื่อวางแผนและแก้ปัญหาทางเศรษฐกิจในระดับ  

ปัจเจกและระดับองค์กรได้อย่างเหมาะสม  

2. ด้านทักษะ (Skills)  

PLO3	มีทักษะการใช้เทคโนโลยีและวิทยาการข้อมูล (Data Science) เพื่อการวิเคราะห์และคาดการณ์ตัวแปรและปรากฎการณ์ทางเศรษฐกิจ  

PLO4	มีทักษะการใช้กระบวนการวิจัยในการวิเคราะห์ สังเคราะห์ในฐานะนักเศรษฐศาสตร์ได้อย่างเป็นเหตุเป็นผล  

PLO5	มีทักษะการสื่อสารภาษาไทยและภาษาอังกฤษ เพื่อใช้ในชีวิตประจำวัน และในการทำงานด้านเศรษฐศาสตร์ ทั้งการฟัง พูด อ่าน เขียน และเสนอผลงานได้ตามวัตถุประสงค์ ในกรณีที่นักศึกษาเลือกภาษาจีนสามารถสื่อสารภาษาจีนในชีวิตประจำวันได้ 

PLO6 มีทักษะในการปรับตัวให้เข้ากับการเปลี่ยนแปลงด้านต่าง ๆ ของสังคม สุขภาพ เศรษฐกิจ วัฒนธรรมและสิ่งแวดล้อม 

3. ด้านจริยธรรม (Ethics)  

PLO7	แสดงออกซึ่งความกตัญญู ความซื่อสัตย์ และปฏิบัติตามกฎระเบียบของสังคม  

PLO8	มีความรับผิดชอบต่อตนเอง สังคมและสิ่งแวดล้อม ที่มุ่งสู่เป้าหมายการพัฒนาที่ยั่งยืน  

4. ด้านลักษณะบุคคล (Character)  

PLO9	แสดงออกถึงการมีภาวะผู้นำ สามารถเป็นได้ทั้งผู้นำและผู้ตาม กล้าเสนอแนะข้อคิดเห็นอย่างตรงไปตรงมา มีวินัย มีจิตอาสา และทำงานร่วมกับผู้อื่นได้  

PLO10	ใฝ่เรียน ใฝ่รู้และพัฒนาตนเองอย่างต่อเนื่อง 

ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา (Learning Outcome: LO) 

1. ด้านความรู้ (Knowledge)  

LO1: ผู้เรียนสามารถประยุกต์ใช้ความรู้ทางเศรษฐศาสตร์ในการปฏิบัติงานในองค์กรอย่างเหมาะสม โดยคำนึงถึงบริบทของสถานประกอบการและสถานการณ์จริง

2. ด้านทักษะ (Skills) 

LO2: ผู้เรียนสามารถใช้เทคโนโลยีและวิทยาการข้อมูล (Data Science) ในการวิเคราะห์ข้อมูลและสนับสนุนกระบวนการทำงานในสถานประกอบการได้อย่างมีประสิทธิภาพ

LO3: ผู้เรียนสามารถใช้กระบวนการวิจัยเพื่อวิเคราะห์ สังเคราะห์ และนำเสนอข้อมูลในฐานะนักเศรษฐศาสตร์ได้อย่างเป็นระบบ เพื่อตอบโจทย์งานที่ได้รับมอบหมายและจัดทำรายงานสหกิจศึกษาที่สมบูรณ์

LO4: ผู้เรียนสามารถสื่อสารและประสานงานกับเพื่อนร่วมงานและบุคลากรในสถานประกอบการ ทั้งภาษาไทยและภาษาอังกฤษได้อย่างมีประสิทธิภาพเพื่อบรรลุเป้าหมายของงาน

LO5: ผู้เรียนสามารถปรับตัวและรับมือกับการเปลี่ยนแปลงในสถานประกอบการ เช่น สภาพแวดล้อมการทำงาน หรือวัฒนธรรมองค์กรได้อย่างเหมาะสม 

3. ด้านจริยธรรม (Ethics)	 

LO6: ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบและคำนึงถึงจริยธรรม

LO7: ผู้เรียนสามารถปฏิบัติตามระเบียบและวัฒนธรรมองค์กร

4. ด้านลักษณะบุคคล (Character)  

LO8: ผู้เรียนสามารถทำงานร่วมกับผู้อื่นได้อย่างมีประสิทธิภาพทั้งในฐานะผู้นำและผู้ตาม พร้อมแสดงออกถึงความคิดสร้างสรรค์และข้อเสนอแนะที่เป็นประโยชน์ต่อองค์กร

LO9: ผู้เรียนสามารถพัฒนาตนเอง เรียนรู้อย่างต่อเนื่อง และเตรียมความพร้อมเพื่อก้าวเข้าสู่วิชาชีพในอนาคต
