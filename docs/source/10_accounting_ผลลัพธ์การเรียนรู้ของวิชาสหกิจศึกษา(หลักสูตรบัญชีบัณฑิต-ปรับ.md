หลักสูตรบัญชีบัณฑิต (ปรับปรุง พ.ศ. 2567)

ผลลัพธ์การเรียนรู้ของหลักสูตร (Program Learning Outcomes: PLOs)

ด้านความรู้ (Knowledge) 

PLO1 อธิบายหลักการบัญชี มาตรฐานการรายงานทางการเงิน เพื่อจัดทำสารสนเทศที่สนับสนุนการตัดสินใจและเป็นประโยชน์ต่อผู้ใช้ 

PLO2 อธิบายความรู้ด้านสังคมศาสตร์ทั่วไป มนุษย์ศาสตร์ เทคโนโลยีสารสนเทศ องค์กรและธุรกิจ ประกอบด้วย หลักการจัดการ เศรษฐศาสตร์ กฎหมาย ข้อบังคับที่เกี่ยวข้องกับวิชาชีพบัญชี 

PLO3 ประยุกต์ใช้ความรู้หลักการบัญชี มาตรฐานการรายงานทางการเงิน ด้านองค์กรและธุรกิจ เพื่อจัดทำรายงานทางการเงินตามมาตรฐานวิชาชีพ และวิเคราะห์รายงานทางการเงินได้

PLO4 ประยุกต์ใช้ความรู้ด้านการสอบบัญชี เพื่อปฏิบัติงานสอบบัญชีและแสดงความเห็นต่องบการเงินในสถานการณ์ต่าง ๆ ได้

PLO5 ในกรณีที่นักศึกษาเลือกกลุ่มวิชาชีพการบัญชีเพื่อองค์กรธุรกิจ สามารถออกแบบระบบบัญชี ประยุกต์ใช้เทคโนโลยีสารสนเทศในการจัดทำ และนำเสนอรายงานทางการเงินที่เหมาะสมตามลักษณะเฉพาะของกิจการได้ และในกรณีที่นักศึกษาเลือกกลุ่มวิชาชีพการสอบบัญชี สามารถประยุกต์ใช้เทคโนโลยีสารสนเทศ เพื่อปฏิบัติงานสอบบัญชีและแสดงความเห็น ต่องบการเงินในกิจการที่มีลักษณะเฉพาะได้ 

ด้านทักษะ (Skills)	

PLO6 มีทักษะการสื่อสารโดยใช้เทคโนโลยีสารสนเทศ ร่วมกับทักษะในการใช้ภาษาไทยและภาษาอังกฤษ เพื่อใช้ในชีวิตประจำวันและในการทำงานด้านวิชาชีพบัญชี ทั้งการฟัง พูด อ่าน เขียน และเสนอผลงาน ในกรณีที่นักศึกษาเลือกภาษาจีน สามารถสื่อสารภาษาจีนในชีวิตประจำวันได้

PLO7 มีทักษะการแก้ปัญหา โดยใช้กระบวนการวิจัย การวิเคราะห์ข้อมูลทางด้านบัญชีเชิงปริมาณและเชิงคุณภาพ นำไปสู่การใช้ข้อมูลทางบัญชีในการแก้ปัญหาในการดำเนินงานขององค์กรได้

ด้านจริยธรรม (Ethics)	

PLO8 ปฏิบัติตามมาตรฐานและจรรยาบรรณทางวิชาการและวิชาชีพบัญชี

PLO9 แสดงออกถึงความกตัญญู ความรับผิดชอบต่อตนเอง ผู้อื่น สังคม และปฏิบัติตามกฎหมายและกฎระเบียบของสังคม

ด้านลักษณะบุคคล (Character) 

PLO10 ปฏิบัติตนในฐานะผู้นำและผู้ตาม ยอมรับในความหลากหลาย มีวินัย มีจิตอาสา มีสุขภาวะที่ดี และสามารถทำงานร่วมกับผู้อื่นได้

PLO11 แสดงออกถึงการปรับตัวตามสถานการณ์ที่เปลี่ยนแปลงในศาสตร์ทางการบัญชี รู้เท่าทันการเปลี่ยนแปลงของสังคมและของโลก เพื่อพัฒนาตนเองได้อย่างต่อเนื่อง

แบบประเมินผลการปฏิบัติสหกิจศึกษาตามผลลัพธ์การเรียนรู้ที่คาดหวัง หลักสูตรบัญชี (ปรับปรุง พ.ศ. 2567)

| ผลลัพธ์การเรียนรู้ของวิชาสหกิจศึกษา (Learning Outcome: LO) หลักสูตรบัญชี (ปรับปรุง พ.ศ. 2567) 
ด้านความรู้ (Knowledge) 
LO1: ผู้เรียนสามารถประยุกต์ใช้หลักการบัญชี มาตรฐานการรายงานทางการเงิน และศาสตร์ที่เกี่ยวข้องกับวิชาชีพบัญชี ในการปฏิบัติงานสถานประกอบการได้อย่างเหมาะสม

ด้านทักษะ (Skills)
LO2: ผู้เรียนสามารถวิเคราะห์และแปลผลข้อมูลทางบัญชี เพื่อสนับสนุนการตัดสินใจในสถานประกอบการได้
LO3 ผู้เรียนสามารถสื่อสารด้วยภาษาไทยและภาษาอังกฤษในการปฏิบัติงานบัญชีได้อย่างมีประสิทธิภาพ
LO4: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานบัญชีด้วยตนเองได้

ด้านจริยธรรม (Ethics)	
LO5:  ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบ และคำนึงถึงจรรยาบรรณวิชาชีพบัญชี

ด้านลักษณะบุคคล (Character) 
LO6: ผู้เรียนสามารถทำงานร่วมกับทีมได้อย่างมีประสิทธิภาพ และแสดงความเป็นผู้นำ |

| (1) ด้านความรู้ (Knowledge) |  |

| LO1: ผู้เรียนสามารถประยุกต์ใช้หลักการบัญชี มาตรฐานการรายงานทางการเงิน และศาสตร์ที่เกี่ยวข้องกับวิชาชีพบัญชี ในการปฏิบัติงานสถานประกอบการได้อย่างเหมาะสม | 5 (ยอดเยี่ยม): ประยุกต์ใช้หลักการบัญชีได้อย่างคล่องแคล่ว ถูกต้อง และสร้างสรรค์
4 (ดีมาก): ประยุกต์ใช้หลักการบัญชีได้ดี มีข้อผิดพลาดเล็กน้อยที่ไม่กระทบต่อผลลัพธ์
3 (ดี): ประยุกต์ใช้หลักการบัญชีในระดับพื้นฐาน แต่ขาดความสามารถในการประยุกต์ใช้แบบเจาะจงหรือลึกซึ้ง
2 (พอใช้): ประยุกต์ใช้หลักการบัญชีได้บางส่วน ต้องการคำแนะนำ และยังขาดความแม่นยำในการปฏิบัติงาน
1 (ต้องปรับปรุง): ไม่สามารถประยุกต์ใช้หลักการบัญชีได้ ยังขาดความรู้พื้นฐานและต้องการเสริมทักษะอย่างมาก |

| (2) ด้านทักษะ (Skills) |  |

| LO2: ผู้เรียนสามารถวิเคราะห์และแปลผลข้อมูลทางบัญชี เพื่อสนับสนุนการตัดสินใจในสถานประกอบการได้ | 5 (ยอดเยี่ยม): วิเคราะห์ข้อมูลเชิงลึก สรุปผลชัดเจน และนำเสนออย่างเป็นระบบ
4 (ดีมาก): วิเคราะห์ข้อมูลได้ดี มีข้อสรุปที่เป็นประโยชน์
3 (ดี): วิเคราะห์ข้อมูลในระดับพื้นฐานและมีข้อสรุปที่ใช้งานได้
2 (พอใช้): วิเคราะห์ข้อมูลได้บางส่วนหรือไม่ครอบคลุม
1 (ต้องปรับปรุง): ไม่สามารถวิเคราะห์ข้อมูลได้อย่างถูกต้อง ขาดทักษะการสรุปผลและนำเสนออย่างมีประสิทธิภาพ |

| LO3 ผู้เรียนสามารถสื่อสารด้วยภาษาไทยและภาษาอังกฤษในการปฏิบัติงานบัญชีได้อย่างมีประสิทธิภาพ | 5 (ยอดเยี่ยม): สื่อสารได้อย่างคล่องแคล่ว ชัดเจน และเหมาะสมกับสถานการณ์
4 (ดีมาก): สื่อสารได้ดี มีข้อผิดพลาดเล็กน้อยไม่กระทบต่อความเข้าใจ
3 (ดี): สื่อสารในระดับพื้นฐานที่สามารถเข้าใจได้ แต่ยังขาดความเข้าใจในบางจุด
2 (พอใช้): สื่อสารได้บางส่วน มีข้อจำกัดด้านความชัดเจนหรือการใช้ภาษา
1 (ต้องปรับปรุง): ไม่สามารถสื่อสารได้อย่างเหมาะสมในสถานการณ์การทำงาน / ฝึกงาน |

| LO4: ผู้เรียนสามารถเรียนรู้และพัฒนาทักษะใหม่ที่เกี่ยวข้องกับงานบัญชีด้วยตนเองได้ | 5 (ยอดเยี่ยม): เรียนรู้และพัฒนาทักษะใหม่ได้อย่างรวดเร็ว และประยุกต์ใช้อย่างมีประสิทธิภาพ
4 (ดีมาก): เรียนรู้และพัฒนาทักษะใหม่ได้ดี มีความเข้าใจเนื้อหา และการใช้งาน
3 (ดี): เรียนรู้และพัฒนาทักษะในระดับพื้นฐาน แต่ยังขาดการประยุกต์ใช้อย่างมีประสิทธิภาพ
2 (พอใช้): เรียนรู้และพัฒนาทักษะได้บางส่วน และต้องการคำแนะนำเพิ่มเติม
1 (ต้องปรับปรุง): ไม่สามารถเรียนรู้และพัฒนาทักษะได้ด้วยตนเอง |

| (3) ด้านจริยธรรม (Ethics) |  |

| LO5:  ผู้เรียนสามารถปฏิบัติงานด้วยความรับผิดชอบ และคำนึงถึงจรรยาบรรณวิชาชีพบัญชี | 5 (ยอดเยี่ยม): ปฏิบัติตามจรรยาบรรณอย่างเคร่งครัด เป็นแบบอย่างที่ดี และแสดงความรับผิดชอบสูงสุด
4 (ดีมาก): ปฏิบัติตามจรรยาบรรณได้ดี มีความรับผิดชอบต่อหน้าที่
3 (ดี): ปฏิบัติตามจรรยาบรรณในระดับพื้นฐาน แต่ยังขาดความรอบคอบในบางจุด
2 (พอใช้): ปฏิบัติตามจรรยาบรรณได้บางส่วน และต้องการคำแนะนำเพิ่มเติม
1 (ต้องปรับปรุง): ไม่ปฏิบัติตามจรรยาบรรณ หรือขาดความรับผิดชอบในงาน |

| (4) ด้านลักษณะบุคคล (Character) |  |

| LO6: ผู้เรียนสามารถทำงานร่วมกับทีมได้อย่างมีประสิทธิภาพ และแสดงความเป็นผู้นำ | 5 (ยอดเยี่ยม): เป็นผู้นำที่ดี ทำงานเป็นทีมอย่างมีประสิทธิภาพสูง และสามารถแก้ปัญหาที่ซับซ้อนได้อย่างเป็นระบบ
4 (ดีมาก): ทำงานเป็นทีมได้ดี มีความรับผิดชอบ แสดงบทบาทผู้นำได้ดีในสถานการณ์ทั่วไป
3 (ดี): ทำงานเป็นทีมในระดับพื้นฐาน แต่ยังขาดความเป็นผู้นำที่ชัดเจน และยังต้องการพัฒนาทักษะในด้านการประสานงาน
2 (พอใช้): ทำงานเป็นทีมได้บางส่วน ยังต้องการคำแนะนำในการปรับปรุงตนเองและการสร้างความสัมพันธ์ในทีม
1 (ต้องปรับปรุง): ไม่สามารถทำงานเป็นทีมได้ หรือหลีกเลี่ยงความรับผิดชอบ |
