# แบบประเมินสหกิจ หลักสูตรการเมืองการปกครอง

> Source: `4. สำนักรัฐศาสตร์ฯ 3 หลักสูตร/แบบประเมินสหกิจ หลักสูตรการเมืองการปกครอง.docx`

Learning Outcome

LO1 มีทักษะการคิด วิเคราะห์และออกแบบงานวิจัยที่สอดคล้องไปกับลักษณะการทำงานในที่ตนปฏิบัติ

LO2 มีทักษะในการรับข้อมูลและจับประเด็นเพื่อแยกแยะ จัดสรรข้อมูลต่างๆให้กับได้อย่างเป็นระเบียบ

LO3 มีทักษะในการถ่ายทอดและนำเสนอประเด็นต่างๆให้สอดคล้องไปกับลักษณะของงานที่ได้รับมอบหมายได้ถูกต้อง

LO4 มีความรับผิดชอบในการปฏิบัติงาน มีวินัยและเคารพกเกณฑ์ต่างๆ

LO5 มีมนุษยสัมพันธ์ที่ดี มีจิตสาธารณะ พร้อมช่วยเหลือเพื่อนร่วมงาน 

 LO6 มีความใฝ่รู้ ขยัน อดทนและพร้อมพัฒนาตนเองอยู่เสมอ

แบบประเมิน LO 

| คำถามสำหรับประเมิน | 1 | 2 | 3 | 4 | 5 |

| 1.นักศึกษามีการวางแผน ปรึกษาและรายงานความคืบหน้าการทำวิจัยกับท่านมากแค่ไหน |  |  |  |  |  |

| 2.นักศึกษาสามารถจับประเด็นคำสั่งและสามารถปฏิบัติงานตามคำสั่งที่ได้รับมอบหมายได้มากน้อยแค่ไหน |  |  |  |  |  |

| 3.นักศึกษาสื่อสารและประสานงานกับผู้ปฏิบัติงานอื่นๆในหน่วยงานของท่านได้มากน้อยแค่ไหน |  |  |  |  |  |

| 4.นักศึกษาสามารถเขียนหนังสือและจัดทำเอกสารเพื่อประสานงานให้กับหน่วยงานของท่านได้อย่างถูกต้องเป็นไปตามระเบียบมากน้อยแค่ไหน |  |  |  |  |  |

| 5.นักศึกษาสามารถอภิปรายถ่ายทอดและนำเสนอประเด็นเกี่ยวกับงานที่ตนได้รับมอบหมายได้อย่างมีประสิทธิภาพมากน้อยแค่ไหน |  |  |  |  |  |

| 6.นักศึกษาแต่งกายในขณะปฏิบัติงานให้กับหน่วยงานของท่านได้อย่างเหมาะสมแค่ไหน |  |  |  |  |  |

| 7.นักศึกษาตรงเวลามากน้อยแค่ไหน |  |  |  |  |  |

| 8.นักศึกษามีความอ่อนน้อมและมนุษย์สัมพันธ์ที่ดีให้กับเจ้าหน้าที่ท่านอื่นๆในหน่วยงานของท่านมากน้อยแค่ไหน |  |  |  |  |  |

| 9.นักศึกษามีความกล้าแสดงออก พร้อมช่วยเหลือเจ้าหน้าที่ในหน่วยงานของท่านมากแค่ไหน |  |  |  |  |  |

| 10.จากการสังเกต ท่านคิดว่านักศึกษามีความขยัน หมั่นเพียร พร้อมพัฒนาตนเองมากน้อยแค่ไหน |  |  |  |  |  |
