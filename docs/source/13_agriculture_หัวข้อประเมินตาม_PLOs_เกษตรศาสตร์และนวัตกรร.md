# หัวข้อประเมินตาม PLOs เกษตรศาสตร์และนวัตกรร

> Source: `13. สำนักวิชาเทคโนโลยีการเกษตรฯ/หัวข้อประเมินตาม PLOs เกษตรศาสตร์และนวัตกรร.docx`

การประเมินตาม PLOs หลักสูตรเกษตรศาสตร์และนวัตกรรม หลักสูตรปรับปรุงปีการศึกษา 2563

PLO1 อธิบายองค์ความรู้ทั่วไปและความรู้ทางนวัตกรรมการเกษตรตามหลักการทางวิทยาศาสตร์ได้อย่าง ถูกต้องเหมาะสม

PLO2 บูรณาการองค์ความรู้ด้านการเกษตรและความรู้ทางด้านธุรกิจการเกษตรได้

PLO3 เลือกใช้เทคโนโลยีและนวัตกรรมทางการเกษตรสมัยใหม่ได้อย่างมีประสิทธิภาพและเหมาะสม

PLO4 เลือกใช้สื่อและเทคโนโลยีสารสนเทศได้อย่างเหมาะสมเพื่อการสื่อสาร และถ่ายทอดองค์ความรู้ทางด้านนวัตกรรมเกษตรทั้งภาษาไทยและภาษาอังกฤษ

PLO5 แสวงหาความรู้ได้ด้วยตนเอง มีการคิดสร้างสรรค์ในการพัฒนานวัตกรรมเกษตร

PLO6 ปฏิบัติตนตามบทบาทและหน้าที่ของตนเอง และสามารถทำงานร่วมกับผู้อื่นได้ โดยยึดหลักคุณธรรม จริยธรรม จรรยาบรรณวิชาชีพ และกฎหมายที่เกี่ยวข้อง

| หัวข้อประเมิน | คะแนนประเมิน |

| มีความรู้ทางนวัตกรรมการเกษตรที่ถูกต้องและสามารถอธิบายหลักการทางวิทยาศาสตร์ที่เกี่ยวข้องได้อย่างชัดเจน |  |

| สามารถประยุกต์ใช้องค์ความรู้ทางวิทยาศาสตร์และเทคโนโลยีการเกษตรเพื่อแก้ปัญหาและพัฒนางานในสถานประกอบการได้อย่างเหมาะสม |  |

| สามารถติดตามและประยุกต์ใช้ข้อมูลข่าวสาร เทคโนโลยี และองค์ความรู้ใหม่ที่เกี่ยวข้องกับวิชาชีพทางการเกษตรได้ทันต่อสถานการณ์ |  |

| สามารถวิเคราะห์และสังเคราะห์ข้อมูลที่เกี่ยวข้องกับงานด้านการเกษตร เพื่อนำไปใช้ในกระบวนการตัดสินใจทางวิชาชีพได้ |  |

| หัวข้อประเมิน | คะแนนประเมิน |

| สามารถนำความรู้ด้านการเกษตรและธุรกิจมาวิเคราะห์และพัฒนาเพื่อเป็นแนวทางในการปฏิบัติงานได้อย่างมีประสิทธิภาพ |  |

| สามารถสรุปประเด็นสำคัญในการดำเนินงานธุรกิจที่เกี่ยวข้องกับสถานประกอบการและแสดงความเข้าใจในกระบวนการทางธุรกิจการเกษตรได้อย่างเหมาะสม |  |

| สามารถคิดวิเคราะห์เชิงระบบ มีเหตุผลรอบด้าน และใช้ความรู้ด้านเกษตรและธุรกิจประกอบการตัดสินใจได้อย่างถูกต้อง |  |

| สามารถแก้ไขปัญหาเฉพาะหน้าที่เกี่ยวข้องกับการดำเนินงานด้านเกษตรและธุรกิจการเกษตรได้อย่างมีประสิทธิภาพ พร้อมมีแนวทางป้องกันปัญหาที่อาจเกิดขึ้นในอนาคต |  |

| สามารถบูรณาการความรู้ด้านการเกษตร เทคโนโลยี และการจัดการธุรกิจ เพื่อพัฒนาแนวทางที่เป็นประโยชน์ต่อสถานประกอบการ |  |

| หัวข้อประเมิน | คะแนนประเมิน |

| สามารถใช้ทักษะด้านนวัตกรรมการเกษตร โดยเฉพาะทักษะทางวิชาชีพได้อย่างถูกต้อง |  |

| สามารถปฏิบัติงานทางวิชาชีพได้อย่างมีประสิทธิภาพ ทั้งในด้านการใช้เครื่องมือ เทคโนโลยี และกระบวนการผลิตทางการเกษตร |  |

| สามารถทำงานได้ด้วยตนเอง ปฏิบัติงานตามมาตรฐานวิชาชีพ และสามารถตัดสินใจแก้ไขปัญหาที่เกี่ยวข้องกับเทคโนโลยีการเกษตรได้อย่างเหมาะสม |  |

| สามารถสรุปประเด็น วิเคราะห์ปัญหา และนำเสนอแนวทางพัฒนาเพื่อปรับปรุงการใช้เทคโนโลยีและนวัตกรรมในสถานประกอบการ |  |

| สามารถเรียนรู้และปรับตัวกับเทคโนโลยีใหม่ๆ ในภาคการเกษตร รวมถึงมีทักษะในการฝึกฝนและพัฒนาตนเองด้านเทคโนโลยีทางการเกษตร |  |

| สามารถประเมินผลกระทบของการใช้เทคโนโลยีและนวัตกรรมที่มีต่อประสิทธิภาพการทำงานและความยั่งยืนของภาคการเกษตรในสถานประกอบการ |  |

| หัวข้อประเมิน | คะแนนประเมิน |

| สามารถสื่อสารและถ่ายทอดองค์ความรู้ด้านนวัตกรรมการเกษตรผ่านสื่อที่เหมาะสม ทั้งในรูปแบบเอกสาร รายงาน และการนำเสนอ |  |

| สามารถใช้ทักษะการฟัง พูด อ่าน และเขียนภาษาไทยและภาษาอังกฤษ เพื่อการสื่อสารทางวิชาชีพได้อย่างชัดเจนและเหมาะสมกับสถานการณ์การทำงาน |  |

| สามารถนำความรู้ทางคณิตศาสตร์และสถิติไปใช้ในการวิเคราะห์ข้อมูลและตัดสินใจในกระบวนการทำงานได้อย่างถูกต้อง |  |

| สามารถใช้ภาษาอังกฤษในบริบทของงานด้านเกษตร ทั้งการสื่อสารทั่วไปและการอ่านเอกสารทางวิชาการหรือคู่มือการทำงานได้อย่างมีประสิทธิภาพ |  |

| หัวข้อประเมิน | คะแนนประเมิน |

| สามารถเรียนรู้และปรับตัวกับงานใหม่ๆ ได้อย่างรวดเร็วและมีประสิทธิภาพ |  |

| สามารถวางแผนการทำงาน กำหนดเป้าหมาย และจัดลำดับความสำคัญของงานที่ได้รับมอบหมายได้อย่างเหมาะสม |  |

| สามารถค้นหาข้อมูลที่เกี่ยวข้องกับงาน ทำความเข้าใจ และสังเคราะห์องค์ความรู้เพื่อนำไปใช้ในการปฏิบัติงานได้อย่างเป็นระบบ |  |

| สามารถแสดงความคิดริเริ่มสร้างสรรค์ในการพัฒนาหรือปรับปรุงงานที่ปฏิบัติให้มีประสิทธิภาพมากขึ้น |  |

| สามารถนำเสนอแนวทางหรือแนวคิดใหม่ๆ ที่นำไปสู่การแก้ไขปัญหาและพัฒนานวัตกรรมทางการเกษตรให้แก่สถานประกอบการได้ |  |

| สามารถประเมินตนเองและพัฒนาทักษะทางวิชาชีพอย่างต่อเนื่องเพื่อเพิ่มประสิทธิภาพในการทำงาน |  |

| สามารถนำเสนอแนวคิดเชิงนวัตกรรมและปรับปรุงงานได้โดยอ้างอิงจากข้อมูลและแนวปฏิบัติที่ดีในอุตสาหกรรมการเกษตร |  |

| สามารถทำงานร่วมกับผู้อื่นและแลกเปลี่ยนความคิดเห็นอย่างสร้างสรรค์เพื่อพัฒนาการทำงานและนวัตกรรมใหม่ๆ |  |

| สามารถจัดการข้อผิดพลาดหรืออุปสรรคในการทำงานด้วยแนวคิดที่สร้างสรรค์และมุ่งเน้นการแก้ปัญหาอย่างเป็นระบบ |  |

| หัวข้อประเมิน | คะแนนประเมิน |

| มีความซื่อสัตย์สุจริต และสามารถแสดงออกถึงความโปร่งใสในการทำงาน |  |

| มีน้ำใจช่วยเหลือผู้อื่นและทำงานร่วมกันในทีมได้อย่างมีประสิทธิภาพ |  |

| มีวินัย ตรงต่อเวลา และสามารถรับผิดชอบต่อการปฏิบัติงานได้อย่างครบถ้วน |  |

| เคารพสิทธิ์และรับฟังความคิดเห็นของผู้อื่นอย่างเปิดกว้าง |  |

| สามารถทำงานร่วมกับผู้อื่นได้ โดยคำนึงถึงความหลากหลายและการทำงานเป็นทีม |  |

| ปฏิบัติตามจรรยาบรรณวิชาชีพ และสามารถแสดงความรับผิดชอบในบทบาทของตนได้ |  |

| มีความรู้พื้นฐานด้านกฎหมายที่เกี่ยวข้องกับวิชาชีพและสามารถปฏิบัติตามได้อย่างถูกต้อง |  |

| สามารถตัดสินใจและดำเนินการภายใต้ข้อจำกัดทางกฎหมายและจริยธรรมในสภาพแวดล้อมการทำงาน |  |
